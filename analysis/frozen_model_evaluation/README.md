# Frozen-model evaluation summaries

The 22 deidentified files in `source_data/` contain the donor-, batch-, assignment- and program-level summaries used in the manuscript. Use `figure_sources.py` to load them and check their values. Filenames follow the original panel numbering.

This directory supports checking saved summaries. Cell-level matrices, source identifier mappings, fitted checkpoints and study-wide prediction arrays are not included here; no fitting, selection or tuning runs here. See `PROVENANCE.json` for the source release. Source-data licence terms remain applicable.
